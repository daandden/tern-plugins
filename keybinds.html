Tern keys migrated from zellij

Every key in this guide comes from the keybinds in ~/.config/tern/settings.json (101 keys). Keys marked Plugin run commands from the zellij-keys, html-links and goto plugins in this repo. The file also clears Tern's own ⌘1–9, ⌘K, ⌘N and ⌘T, so Tern passes those keys to the pane. Use ⌃G T 1–9, Shift twice and ⌥T instead.

Read a key

⌃G P R means: press Ctrl+G, let go, press P, then press R. Tern has no sticky modes. Press the whole sequence for each action.

Alt is the left Option key

option_as_alt is left. Hold the left Option key for the ⌥ keys. The right Option key still types special characters.

Floating panes

The floating panes of a tab are shown or hidden together. Each shown one is half the tab. The first sits in the middle, each later one a little lower and to the right, and the focused one is on top. Yazi, lazygit and btop (F2, F3, F4) open in the middle at 80% of the tab instead. A focus on a normal pane (a click, a key or an open) hides them, and their programs keep running. ⌥F from a normal pane shows them again and focuses the one you used last. A switch to another tab or session hides nothing.

If a key stops working

  • Tap Shift twice to open the command palette, and run Reload settings. Tern reads settings.json only at start and on reload.
  • Close Tern Settings before you edit settings.json by hand. An open Settings page keeps the keys it had when it opened. When you change anything there, even its width, it writes those old keys back to the file. If keys go back to old values, close Settings, fix the file, and run Reload settings.
  • If F1 to F4 or other Plugin keys do nothing, run Reload plugins from the palette.
