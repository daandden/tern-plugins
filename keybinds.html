Tern keys migrated from zellij

This guide lists 99 key sequences, all bound in ~/.config/tern/settings.json. Keys marked Plugin run commands from zellij-keys or goto. The settings file also clears Tern's own ⌘1–9, ⌘K, ⌘N and ⌘T, so Tern passes those keys to the pane. Use ⌃G T 1–9, Shift twice and ⌥T instead.

Read a key

⌃G P R means: press Ctrl+G, let go, press P, then press R. Tern has no sticky modes. Press the whole sequence for each action.

Alt is the left Option key

option_as_alt is left. Hold the left Option key for the ⌥ keys. The right Option key still types special characters.

Floating panes

Tern draws floats in native corner decks, at most four per corner, and fans a deck on hover. A focused float grows, and an unfocused one shrinks to a glance. Mouse dragging works. Yazi, lazygit and btop (F2, F3, F4) ask Tern for 80% of the tab. Tern draws the focused float at about 70% of the tab and its glance smaller. Tern's own ⌃⌥⌘P (Hide pictures in picture in the palette) hides or shows the tab's floats; its direction can follow your last use in another tab. Their programs keep running while hidden. Focusing a tiled pane leaves floats shown as glances. When a focused float closes, the plugin focuses the last used shown float, else the one before or after it.

Resize: Ctrl+G, then R

Zellij's resize mode. Press the whole sequence again for each step. Directional keys use native resize_split:*. A float stays in its corner, and the key moves its edge away from the corner that way, so L widens a float on the left and narrows one on the right. Grow and shrink combine two native resize actions and do nothing in a tiled pane.

If a key stops working

  • Tap Shift twice to open the command palette, and run Reload settings. Tern reads settings.json only at start and on reload.
  • Close Tern Settings before you edit settings.json by hand. An open Settings page keeps the keys it had when it opened. When you change anything there, even its width, it writes those old keys back to the file. If keys go back to old values, close Settings, fix the file, and run Reload settings.
  • If F1 to F4 or other Plugin keys do nothing, run Reload plugins from the palette.
  • While the page of a browser block has the keyboard, only ⌘ keys reach Tern (Tern 0.9.18). ⌥ keys, ⌃G sequences and F keys go to the page, so ⌥X does not close it. Press ⌘W to close the block.
