# Zellij floats and panes

The zellij-keys plugin keeps focus among shown floats when one closes, opens floating tools, grows or shrinks a float, breaks panes out to tabs, and adds focus-or-tab keys. Tern draws floats in native corner decks. Hiding and showing floats, directional focus, moving, docking, splitting, and resizing use Tern's own actions.

## Sub-features

- `zk-close-float` focuses the last used shown float when the focused float closes, else the one before it in open order, else the one after it. Closing the last float leaves focus tiled.
- `zk-picker` returns to the float that opened Go to when Esc closes the picker. A jump to another pane keeps that target.
- `zk-float-tool` opens yazi, lazygit, or btop with F2, F3, or F4. Native `size = { 0.8, 0.8 }` sets glance size. Focus grows the float to Tern's cap: 892 by 511 px in a 1280 by 800 window on 0.9.16. The float closes when its tool exits.
- `zk-corners` uses native corner decks, at most four drawn floats per corner, fanned on hover. An unfocused float shrinks to a glance. Mouse dragging and float motion remain native.
- `zk-grow` grows or shrinks the focused float with Alt+=, Alt+Shift+=, Alt+-, Ctrl+G, R, +, or Ctrl+G, R, -. Each press runs one native `resize_split` step in width and one in height, with directions picked from the float's corner: right and down grow a `tl` float, left and down a `tr` float, right and up a `bl` float, left and up a `br` float. The float stays in its corner. These commands do nothing in a tiled pane.
- `zk-native-layout` uses native `split_right` on Alt+N and Ctrl+G, P, N, native `pip` on Ctrl+G, P, E, native `move_pane:*` on Ctrl+G, M, and native `resize_split:*` on Ctrl+G, R. Ctrl+G, R, = runs native `equalize` for tiled panes only.
- `zk-break` moves the focused pane to a new tab (Ctrl+G, T, B), or to the tab on the left or right (Ctrl+G, T, `[` or `]`).
- `zk-focus` uses native `focus_pane:*` for directional focus. Alt+H and Alt+L try native focus left or right, then the previous or next tab when focus did not move. Alt+J and Alt+K never switch tabs.
- `zk-agent-tab` opens a new tab with an agent block in the folder of the focused pane (Alt+Shift+T). The key runs Tern's own `new_agent_block`, and the copied `settings.json` sets `agent_placement` to `new_tab`, so Tern's `New agent block` in the palette opens a tab too.
- `zk-worktree-agent-tab` opens an agent tab in a new worktree at the remote default branch (Ctrl+Shift+T), while the clean main checkout keeps its current branch. Dirty main checkouts and ahead or diverged local default branches stop with an error toast. A failed fetch uses the cached remote branch; without it, the local default branch is the fallback. Repos with Git LFS work although the window's `PATH` has no Homebrew. A failed add names its cause in the toast and removes the press's folder and its `wt/<time>` branch, unless the branch moved. A press whose path or `wt/<time>` branch already exists stops before the add and changes nothing, and a branch of that name that another tool tries to make after the press claimed it cannot be made.
- `zk-scroll` scrolls the focused terminal pane with Tern's actions on Ctrl+G, S: J and K one line, Ctrl+F or Page Down and Ctrl+B or Page Up one page, Ctrl+C to the bottom. With the find bar open (Ctrl+G, S, F), N goes to the next match toward the newest output and P to the previous one.
- `zk-reload-page` reloads the focused browser block on Cmd+R, also while its page has the keyboard, and leaves the page undriven. In SQLite, Cmd+R still runs Tern's own refresh or Execute. In a terminal pane, it changes nothing.

## How to get to it (user POV)

- The keys above, from `settings.json`. `keybinds.html` lists them under the Zellij mode of each.
- The plugin palette entries `Float yazi`, `Float lazygit`, `Float btop`, `Grow the floating pane`, `Shrink the floating pane`, `Break pane to new tab`, `Break pane to the tab on the left`, `Break pane to the tab on the right`, `Focus the pane or tab on the left`, `Focus the pane or tab on the right`, `New agent tab in a new worktree`, and `Reload page` (in a browser block only).
- Tern's native split, float and dock, move, focus, resize, equalize, and `New agent block` actions.

## Driving it with tern-verify

Preconditions:

- The baseline from `README.md`, with one tiled pane. Read its id from `tern ls`, rather than assuming an id.
- The copied keymap must use the targets in `keybinds.html`. If the user's settings have not been rebound yet, record key checks as blocked by the old targets. A command run alone does not prove a key binding.
- A layout line per pane: `L() { "$V" tern "$RUN" ls | grep -E '^ +[0-9]+'; }`. A float shows `pip <corner> over <id>`, a hidden float `stashed <side>`.

- Split. Run `"$V" ctl "$RUN" key alt+n`. `L` shows a second tiled pane. Repeat Ctrl+G, P, N from a focused float and confirm native splitting, not another floating shell.
- Create floats. With two tiled panes, focus one and send `key ctrl+g`, `key p`, `key e`. `L` shows it as `pip <corner> over <other>`. F2, F3, and F4 create additional tool floats. Use those paths for float fixtures.
- Tiled focus. With floats shown, run `"$V" tern "$RUN" focus <tiled id>`. The floats remain shown as native glances.
- Close focus. With three floats shown, focus a middle float and close it with `"$V" ctl "$RUN" close`. Focus goes to the previous float in open order, else the next. Close the last float and confirm tiled focus. To check last-used focus, open the Go to picker from a non-newest float and close it with Esc: focus returns to that float. Reload zellij-keys and repeat to check that the last-used choice survives reload.
- Picker target. From a shown float, run `"$V" ctl "$RUN" plugins run plugin.goto.open`, then `key escape`. Repeat with F1. Both return to the opener float. For a jump in a split tab, open F1, press `ctrl+;`, and type `a` to show plain panes. Read `opts` from `goto.md`, choose a tiled pane other than the one under the picker, and jump to it. That target keeps focus, and the floats remain shown as glances.
- Tool size. Run F2 and record `L`, `ctl state`, and `dump '.tn-stage > .pip:not(.off)'`. Move focus to a tiled pane and record the Yazi glance rectangle. Focus Yazi again and record the grown rectangle. On 0.9.16 in a 1280 by 800 window, `.size` is `[1019,584]` and the settled focused rect is 892 by 511 over a full-width owner (446 by 511 over a half-width one). Repeat with F3 and F4, and quit each tool or close its pane to confirm close-on-exit behavior.
- Corner decks. Open five tool floats in one corner. Record `ctl state` and `dump '.tn-stage > .pip:not(.off)'` before hovering. At most four are drawn in that corner. Use `"$V" ctl "$RUN" pip fan '"#1"'` for the stack of the oldest float, as a controlled equivalent of hovering, and record the fanned deck. Fan another corner to fold the first deck. No automatic distribution among corners is expected.
- Native move. Focus a float and send Ctrl+G, M, H or Left, then L or Right, then K or Up, then J or Down, always with the whole chord. `L` shows its native corner change. Repeat in tiled panes and record the native pane move.
- Grow and shrink. Use a float small enough to grow without reaching Tern's frame limit. Record its corner and `.pip-focus` rectangle. Alt+= and Alt+Shift+= grow it by 32 px in width and height. Alt+- shrinks it by the same. Repeat Ctrl+G, R, `shift+=` and Ctrl+G, R, `-`. Do this in each of the four corners (Ctrl+G, M moves the float between corners). The corner stays fixed. Repeat on a tiled pane and confirm that these plugin commands change nothing.
- Native resize and equalize. In a float, send Ctrl+G, R, H, L, K, J and each arrow, one whole chord per step. Record native width and height changes with the corner unchanged. In a split tab, repeat to move its dividers, then run Ctrl+G, R, = to equalize tiled panes. A focused float is not reset by equalize.
- Native drag. Drag a float by its native header in the isolated window. Record its rectangle before and after, then focus a tiled pane and the float again. Tern retains control of the float's position and glance behavior. If the available control tooling cannot perform a drag without coordinates, record this user path as skipped rather than claiming the move keys prove dragging.
- Agent tab. Make `RUN/data/agent-sub`, `cd` the shell pane into it and check that `RUN/data/config/settings.json` has `"agent_placement": "new_tab"`. Press `"$V" ctl "$RUN" key alt+shift+t`. `ctl state` shows one more tab, active, and its focused pane runs omp in `agent-sub` (`.focused.cwd`). The shot shows the agent block and its composer. Close the tab with `"$V" ctl "$RUN" close`. Then focus the shell pane again, run `"$V" ctl "$RUN" palette '"New agent block"'` and `key enter`: one more tab again, not a split of the shell's tab.
- Scroll. Run `"$V" type "$RUN" 'seq 300'`. Read `"$V" ctl "$RUN" tree '.tn-pane.on:not(.off) .tv' | jq -r '.nodes[0].class'` (`tv`, or `tv scrolled` when the view is not at the bottom) and `"$V" ctl "$RUN" dump '.tn-pane.on:not(.off) .tv-thumb' | jq -c '.elements[0].rect'` (the scroll bar thumb). Ctrl+G, S, K gives `tv scrolled` and moves the thumb up a little, and Ctrl+G, S, J moves it back down by the same amount. Ctrl+G, S, Ctrl+B and Ctrl+G, S, `pageup` move it up much more (a page), and Ctrl+G, S, Ctrl+F and `pagedown` move it down a page. Ctrl+G, S, Ctrl+C gives `tv` and the thumb at its first place.
- Find. Press Ctrl+G, S, F. `"$V" ctl "$RUN" state | jq -c .find` is no longer `null`. Clear the bar with `key cmd+a` and `key backspace`, then run `"$V" ctl "$RUN" type 29`. `.find` gives `hits` above 1 and `current` equal to `hits` (the newest match). Ctrl+G, S, P lowers `current` by 1, and Ctrl+G, S, N raises it by 1. `key escape` closes the bar (`null`).
- Worktree fixture. Under `RUN/data`, make a bare `origin.git`, push a first commit, and clone it to `repo` and `other`. In `repo/.omp/config.yml`, set `worktree.base` to an absolute directory under `RUN/data`, such as `RUN/data/wt`. Add `.omp/` to the fixture repo's `.git/info/exclude` so the config does not make the checkout dirty. Run `git -C repo remote set-head origin -a`, switch `repo` to a new branch `feature`, and push a second commit to `master` from `other`. Give every further fixture clone its own `worktree.base`, such as `RUN/data/wt-<clone>`: clones of one origin pick the same `wt-<time>-<commit>` folder names.
- Worktree agent tab. In the shell pane, `cd` into `repo` and press `"$V" ctl "$RUN" key ctrl+shift+t`. `tree .toast` says `Updating master…`, and `tern ls` shows one new tab with omp in `RUN/data/wt/wt-<date>-<commit>`. Its HEAD is the second commit, and `repo` stays on `feature`. Repeat through the palette's `New agent tab in a new worktree`. Repeat from an existing fixture worktree and check that the main checkout still keeps its branch.
- Default branches. Repeat with `origin/HEAD` naming `main` and a nonstandard branch such as `trunk`. With `origin/HEAD`, adding the other local default branch does not change the chosen branch. Without an origin, exactly one local `main` or `master` opens a worktree. Both names or neither name give `No default branch` and create no tab.
- Worktree rejection. Each case leaves the worktrees unchanged and gives a toast whose classes include `toast` and `err`: an untracked file, a staged change, an unstaged change, a local commit on `master` (`1 unpushed commit`), diverged local and remote commits (`diverged`), and the shell pane in `RUN/data` (`Not in a git repo`). Wait for the toast to disappear before the next key.
- Failed fetch. An origin URL that does not exist gives an info toast and opens at cached `origin/master`. Remove the fixture's `refs/remotes/origin/master` and repeat to check the local `master` fallback. A failed fetch still rejects a known ahead or diverged local default branch.
- Fetch deadline. Use a loopback TCP listener that accepts a connection but sends no SSH banner, and set the fixture's origin to `ssh://git@127.0.0.1:<port>/fixture.git`, keeping its cached `origin/master`. Press Ctrl+Shift+T, then press it twice more while the fetch waits. After about 30 seconds (at most 31 seconds plus UI scheduling), the command shows `Could not reach origin; master may be old` and opens one agent tab. No extra tab opens from the busy presses. Stop the listener and remove the fixture's worktrees and agent sessions.
- Git LFS. Make a bare `lfs-origin.git`, and in a clone of it run `git lfs install --local`, `git lfs track '*.bin'`, commit `data.bin` with the text `LFS-CONTENT`, and push. Clone it to `lfs-repo`, run `git lfs install --local` there (it writes `post-checkout` and the other hooks), and set its `worktree.base`. Press Ctrl+Shift+T in `lfs-repo`: one omp tab opens in the new worktree, and its `data.bin` holds `LFS-CONTENT`, not an LFS pointer. On a head without the fix, the toast says `git-lfs: command not found` and no tab opens.
- Failed add. In a fixture clone `hook-repo`, make `.git/hooks/post-checkout` executable with `printf '\nboom: hook failed\n' >&2; exit 1`. Record `git -C hook-repo branch --list 'wt/*'` and its `worktree.base` folder, then press Ctrl+Shift+T. `tree .toast` shows `Could not add a worktree` with `boom: hook failed`, no tab opens, and the branches and folder match the record. Make another clone `locked-repo`, create its `.git/worktrees` and `chmod 555` it: the add fails with `Permission denied` before git lists a worktree, and the press's folder and branch are gone. Make a clone `moved-repo` whose `post-checkout` runs `git commit -q --allow-empty -m moved` before the same failure: the toast says `Could not remove wt/<time>`, and that branch stays with the new commit.
- Branch race. In a clone with the failing hook, watch its `worktree.base` folder in a tight loop (1 ms) and, as soon as `wt-<time>-<short>` appears, run `git branch wt/<time> origin/master`, as another tool would. Press Ctrl+Shift+T. With the fix, that `git branch` fails with `already exists`, the toast shows `boom: hook failed`, and no `wt/*` branch, worktree or prunable entry stays. On a head that checks the branch with `rev-parse`, the competitor's branch is made, omp reuses it, and the cleanup deletes it.
- Taken names. In a clone `taken-repo`, run `git worktree add -b wt/<time> <base>/wt-<time>-<short> origin/master` for the stamps (`date +%Y%m%d-%H%M%S`) of the next 60 seconds, with `<short>` from `git rev-parse --short=7 origin/master`, and put a file `KEEP` in each. Press Ctrl+Shift+T at once: the toast says `wt/<time> already exists`, and every pre-made worktree keeps its folder, `KEEP` and branch. Repeat in a clone with only the 60 branches (`git branch wt/<time> origin/master`): the same toast, and no folder appears. Repeat in a clone with only the 60 folders, each with `KEEP`: the toast says `Could not make the worktree folder`, the folders keep `KEEP`, and no `wt/*` branch appears.
- Float and dock. With two tiled panes, focus one and press `"$V" ctl "$RUN" key ctrl+g`, then `key p`, then `key e`. `L` shows that pane as `pip <corner> over <other>`. The same keys again dock it, and it is tiled again.
- Break to a new tab. Press `key ctrl+g`, `key t`, `key b`. `"$V" ctl "$RUN" state | jq -c '[.tabs[] | {panes, active}]'` shows one more tab, active, with the pane.
- Break to the left. In the new tab, press `key ctrl+g`, `key t`, `key '['`. The tab list loses that tab, and the tab on the left has one more pane.
- Break to the right. Press `key ctrl+g`, `key t`, `key ']'`. The focused pane moves to the tab on the right. At the last tab, Tern creates a new tab.
- Focus. In a split tab, exercise Alt+H and Alt+L, including their Left and Right arrow alternatives. They first use native directional focus, then switch tabs only when focus did not move. Exercise Alt+J, Alt+K, Alt+Down, and Alt+Up: they use native focus without a tab fallback. Repeat Ctrl+G, P with H, J, K, L and every arrow. From a float, observe native directional focus rather than an open-order float cycle.
- Reload page. Write `RUN/data/rnd.html` as `<h1 id=t></h1><script>t.textContent=String(Math.random())</script>`. Open a page with `"$V" tern "$RUN" browser '{"op":"open","owner":<shell id>,"url":"https://example.com","how":"beside"}'`, send it to `file://<RUN>/data/rnd.html` with the op `goto`, and `release` it. Read the number with `"$V" ctl "$RUN" webcall '.tn-pane.on:not(.off) .kit-web-page' '{"op":"eval","function":"() => t.textContent"}'`. Click into the page and press Cmd+R with `computer` window input (`win.click`, then `win.press("cmd+r")`): `ctl key` reaches Tern's UI even when the page has the keyboard, so it does not prove the page path. The number changes, and the `blocks` op still lists the page with `"driven":false`. From the shell pane, Cmd+R leaves the number alone. In a SQLite block (`tern open t.db`, Browse), insert a row with `/usr/bin/sqlite3` and press Cmd+R: the grid shows the row.
- Palette. Repeat every plugin entry named above and the native layout entries. Observe the same state change as with the corresponding key. Keep key and palette evidence separate.
- Proof. Run `"$V" shot "$RUN" zk-<step>` after each layout change. Capture native focused rectangles, unfocused glances, corner decks, and the shown or stashed state in the matching layout output.

## Gotchas

- Ctrl+G, P, E does not float the only tiled pane of a tab. Split first.
- lazygit in `RUN/data`, which is not a git repo, asks to make one, and `q` does not quit it. Close its float with `"$V" ctl "$RUN" close`.
- A chord is one `key` call per key, and each step needs the whole chord. A bare `l` after Ctrl+G, M, L types into the pane. Page Up and Page Down are `pageup` and `pagedown` in `ctl key`.
- The find bar keeps its last query. Clear it before typing a new one.
- The agent-tab check runs omp in `agent-sub`, not directly in `RUN/data`. After `stop`, remove only its session directory for this run.
- F2, F3, and F4 can refocus their new float after the key returns. Poll `.focused.id` before continuing with a mixed-state fixture.
- The plugin process inherits Tern's launcher PATH, not the fish pane's PATH. Keep the absolute Homebrew paths.
- `stop` deletes worktrees under `RUN/data`, but nested agent session directories remain under `~/.omp/agent/sessions/`. Remove only directories whose encoded path starts with this run's `RUN/data` path.
- Focus the shell pane (`"$V" tern "$RUN" focus <id>`) before typing `cd` for the next worktree press. A press focuses its new omp tab, and a line typed there goes to omp as a prompt. Close each new omp tab after its check.
- `.tabs[].panes` in `ctl state` counts tiled panes only. Count floats from `L`.
- `glance` is native shown-but-unfocused state. `hidden` is stashed state. Deck visibility is separate: `.pips[].deck` may be `whole`, `peek1` to `peek3`, or `hidden`.
- goto closes its picker before focusing a jump target. A jump to the tiled pane under the picker gives the same events as Esc and returns to the last used float.
- The stage retains panes of tabs already visited, with `off`. Select drawn panes with `.tn-stage > .pip:not(.off)`.
- `tern ls` lists floats in no fixed order, and pane sizes can lag behind the window. Measure rectangles with `dump`.
- Alt+F and Ctrl+G, P, W are unbound. Confirm that neither key changes `.pips[].mode` of a tab with shown floats.
- A hand edit of the running window's `settings.json` does not apply and can be overwritten. Bind through Keyboard settings or `cx.settings:bind`, or prepare the keymap before starting the isolated window.
